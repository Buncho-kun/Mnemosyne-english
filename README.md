# Mnemosyne（ムネモシュネ）

英語学習アプリ。単語・熟語・文法・英文解釈・英作文・会話・リスニングを、3年で3周する学習プランに沿って進める。

## 開き方

`index.html` をブラウザで開く（GitHub Pages で公開する場合は、リポジトリの Settings → Pages で `main` ブランチのルートを指定）。

- 学習記録はブラウザ（localStorage）に保存される。設定の「記録のバックアップ」で書き出し・読み込みができる。
- AI添削・AIとの会話・要約の採点は、claude.ai のアーティファクトとして開いたときだけ動く。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 画面とスタイル |
| `app.js` | アプリ本体 |
| `loader.js` | データを読み込んでから本体を起動する（`build.py` が生成） |
| `data-all.js` | 全データをまとめたもの（`build.py` が生成） |
| `src/` | データの元ファイル。読み込み順は `src/data-order.txt` |
| `build.py` | `src/` から `data-all.js` と `loader.js` を作り直す |
| `*.jpg` `*.webp` `*.png` | 起動画面の背景・ロゴ・アイコン |

## データを変えたとき

```
python3 build.py
```

例文・解説・問題文はすべてこのアプリ用に作成したもの。
